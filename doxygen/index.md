## TeamCraft-MP API Documentation

이 사이트는 TeamCraft-MP(및 외부화되지 않은 의존성)의 자동 생성 API 문서입니다.

> [!NOTE]
> TeamCraft-MP는 아직 원본 PMMP의 `apidoc.pmmp.io`처럼 자동으로 호스팅되는 문서 사이트가 없습니다.
> 로컬에서 Doxygen을 직접 돌려서 생성한 문서를 보고 계신 겁니다.

### 참고할 만한 개발 자료 (원본 PMMP 제공, 대부분 그대로 적용됨)
 - [DevTools](https://github.com/pmmp/DevTools/) - 플러그인 개발용 도구
 - [ExamplePlugin](https://github.com/pmmp/ExamplePlugin/) - 기본 API 기능을 보여주는 예제 플러그인
 - [DeveloperDocs](https://devdoc.pmmp.io) - PocketMine-MP 플러그인 개발자용 일반 문서
